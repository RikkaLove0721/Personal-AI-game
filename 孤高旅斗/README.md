# 孤高旅斗

原生 JavaScript + Canvas 的 Q 版格斗小游戏: 支持单人闯关(闯关模式), 角色卡房间人机对战, 以及局域网 2-4 人自由混战。Windows 下双击 exe 即玩, 也可直接用浏览器打开构建产物体验单人内容。

当前版本: 2.7.0

## 功能特性

- 双端统一: 同一份 HTML 电脑打开是键鼠操作, 手机/平板浏览器打开自动切换为虚拟摇杆 + 技能按钮(含平板放大适配、竖屏引导、iOS 音频解锁), 联机互通
- 单人闯关模式: 9 关关卡制 Boss 战, 依次挑战巨龙 / 神秘黑侠客 / 西部快枪手 / 机械蜂后 / 霜甲巨像 / 双子剑客 / 赌徒 / 镜影 / 磁暴坦克, 普通与困难两档难度, 通关获得金币, 连胜可 3 选 1 词条强化
- 角色卡房间: 第一张卡是自己(可当场换装扮/技能), 人机卡可增删(最多 3 个)、可选难度与配装
- 九种对战模式: 经典乱斗 / 阵营(红黄蓝绿四队) / 霸主争霸 / 天外来物 / 缩圈乱斗(多个安全圈逐个塌陷 + 掉落冒险) / 丧尸危机(不限时, 僵尸潮一波波刷新, 战斗界面直接开商店买血包与增益) / 车轮战 / 追猎时刻(随机猎人 1v3 非对称, 猎人伤害随存活幸存者数每多一人 +20%) / 乱斗热身(60-180s 限时刷分), 单人与联机都可选(车轮战仅本地面板)
- 规则修饰符: 低重力 / 高速 / 回复(周期掉血包) / 僵尸(刷新僵尸干扰, 击杀不掉金币且僵尸不放大招) / 技能轮盘, 可多选叠加, 房主开局前勾选
- 大地图摄像机: 战场统一 1200 x 1200, 角色固定屏幕中心, 到边界视角才停
- 局域网对战: 房主开服, 2-4 人同房间开打; 准备阶段所有人都是角色卡, 房主可编排人机与模式
- 技能系统: 6 普攻 + 21 技能 + 8 大招, 格挡可弹反远程攻击, 商店可自由购买搭配; 每个技能都带简短效果标签(如 位移 / 无敌 / 贯穿 / 定身), 手机端点图标即弹介绍浮框
- 索敌机制: V 键循环锁定对手, 锁定目标头顶有黄色三角, 追踪类技能优先朝它出手; 手机端摇杆左下角有同尺寸的「索敌」键
- 通用操作: 双击方向键短距离闪避(冷却 2.5 秒, 无无敌帧, 与普攻共享冷却)
- 成长系统: 金币经济, 三段式皮肤装配(头/上身/下身, 套装页一键购买/整套穿戴, 高清贴图皮肤与老部件自由混搭, 颈面锚点规格见 scripts/proc_skin_naiwa.py), 技能商店自由搭配, 18 项成就 + 称号佩戴(九种对战模式各有一个「获胜 10 次」的专属称号), 每日挑战(固定种子随机关卡+修饰符, 记录最快通关)
- 背景音乐: 随机乱序低音量播放, 主菜单右上角可开关(状态随存档保存)
- 热更新: exe 优先读取同目录的 html, 更新玩法无需重新打包

## 技术栈

| 类别 | 选型 |
|:---:|:---:|
| 前端 | 原生 JavaScript (ES6+) + HTML5 Canvas + WebAudio, 无框架无依赖 |
| 联机 | WebSocket, 服务器为 Python 标准库手写实现(零第三方依赖) |
| 桌面壳 | pywebview (Edge WebView2) |
| 打包 | PyInstaller onefile |
| 测试 | Node.js 内置 vm 模块无头集成测试 |
| 构建 | Python 脚本 scripts/build.py, 将 src/js 模块合并为单文件 html |

## 快速开始

玩家:

1. 进入 dist/ 目录, 双击 孤高旅斗.exe(黑窗口是服务器, 不要关)
2. 联机: 房主创建房间得到 4 位房号, 朋友用浏览器打开房主地址加入(最多 3 位挑战者)
3. 详细玩法见 docs/使用说明.txt

手机 / 平板玩(与电脑同一个游戏, 不需要装任何东西):

1. 双击项目根目录的 启动局域网服务器.bat(英文副本 start_lan.bat, 内容相同)
2. 手机与电脑连同一个 Wi-Fi, 用浏览器打开窗口里显示的地址, 或直接扫弹出的二维码
3. 先横屏, 然后点「多人游戏 → 创建/加入房间」; 手机上 Safari 分享 → 添加到主屏幕可全屏进入

> 页面双端自适应: 手机/平板打开自动切为虚拟摇杆 + 技能按钮, 电脑打开是键鼠操作,
> 混着一起联机也没问题(触屏端插键盘同样可用)。平板会自动放大控件。

开发者:

```
python scripts/build.py --version 2.8.0      # 构建产物到 dist/
node tests/test_smoke.js                     # 集成自测 76 项
node tests/test_v20.js                       # v2.0 起新特性自测 280 项
node tests/test_v26.js                       # 新模式与新系统自测 172 项
node tests/test_v28.js                       # v2.8 BUG 修复与平衡自测 53 项
node tests/test_net.js                       # 联机自测 39 项(含 4 人混战)
node tests/dodge_check.js                    # 闪避与激光波回归 10 项
node tests/shield_dodge_check.js             # 共享 CD 与岩土盾回归 20 项
python src/server/孤高旅斗.py --server       # 开服务器(开发态自动读取 dist/)
node tests/srv_check.js 8123                 # 服务器自测 26 项(含 4 席位)
```

发布前所有 js 测试全绿再打包, 比较稳。

## 目录结构

```
.
+-- AGENTS.md            Agent 开发协作守则与项目信息
+-- README.md            本文件
+-- .gitignore
+-- 启动局域网服务器.bat   双击起服务器, 让手机/平板/别的电脑连进来玩
+-- start_lan.bat        同上(英文名副本, 防中文路径/文件关联出问题)
+-- dist_balance_ref.js  平衡配置备份参考
+-- docs/                文档(使用说明, 更新日志)
+-- src/                 源码
|   +-- js/              前端模块(数据/战斗/渲染/联机/界面/触屏 分层)
|   +-- server/          Python 局域网服务器与桌面壳
|   +-- shell.html       页面骨架(构建模板, 含移动端适配)
|   +-- VERSION          版本号
+-- scripts/             构建与辅助脚本
|   +-- build.py         构建单文件产物
|   +-- lan.py           一键局域网开服(打印地址 + 生成二维码)
|   +-- _make_bat.py     生成上面两个 .bat(改 bat 请改这里, 别手改)
+-- tests/               Node.js 无头集成测试
+-- assets/              手工美术资源(预留)
+-- assets-ai/           AI 生成素材(预留)
+-- dist/                构建产物(html 与 exe, 已被 git 忽略)
```

> 触屏适配集中在 src/js/95_touch.js(摇杆/按钮/平板放大, 顶部 CFG 与 BTNS 是调手感入口)
> 与 src/shell.html 的「手机版适配」CSS 段; 90_boot.js 的 applyMobileView/fit 负责分端视口。
> 触屏判定用 matchMedia(hover/pointer), 不能用 "ontouchstart" in window(桌面浏览器恒为 true)。
