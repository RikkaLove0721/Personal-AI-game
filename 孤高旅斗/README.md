# 孤高旅斗

一个用原生 JavaScript + Canvas 写的 Q 版对战游戏。单人闯关、人机对战、局域网联机三种玩法共用同一套角色与技能，双端同源 —— 电脑是键盘鼠标，手机是虚拟摇杆与按钮，混着联机也没有障碍。

当前版本: 4.36

## 玩法一览

- **闯关**：9 关 BOSS 讨伐战，普通 / 困难两档，困难为 2 倍血量、伤害 ×1.4，通关掉落金币
- **勇者格斗**：角色卡房间，编排人机（最多 5 个，难度木桩 / 普通 / 困难，可换配装），选定规则后开打
- **死战闯关**：连打 6 关随机 BOSS，每关之间 3 选 1 拿一个 Buff，通关 50 金币
- **局域网联机**：2-4 人，房主开服，朋友用浏览器输 4 位房号即可加入；除车轮战外 21 种模式都能联机，各模式的动态状态由房主权威下发
- **新手教程**：九步走完操作（移动 / 普攻 / 技能 / 索敌 / 闪避 / 交互 / 开车 / 道具箱 / 大招），首次通关 50 金币
- **成长任务**：通关教程后主菜单左下角出现三行小卡（买皮肤 / 装技能 / 开房间），每项 10 金币，点一行直接跳过去；三项做完卡片自动退休，不再出现
- **人机**：会追人、躲柜子、开车、捡金币、推塔；附近没人的时候还会自己去搜刮补给箱（读条途中有人摸过来会立刻放弃）

## 核心手感

- **闪避**：双击同一方向短距离位移，无无敌帧，与普攻共享 2.5 秒冷却 —— 进攻与保命只能选一个
- **索敌**：`V` 在敌人之间循环锁定（`Shift+V` 反向），追踪类技能优先朝锁定目标出手
- **能量**：命中 +12 / 受击 +10 / 每秒 +2.2，攒满 150 放大招；放大招时全场暂停并给局部特写
- **格挡**：归类在普攻槽，挡下技能或大招的代价更大，还能把远程攻击原路反弹
- **交互**：`P` 键拾取 / 躲柜子 / 上下车 / 搬泥土 / 开补给箱，手机端在大招键正上方

## 快速开始

玩家：

1. 打开 `dist/孤高旅斗.exe`（黑窗口是服务器，别关）；只想玩单人可以双击同目录的 `孤高旅斗.html`
2. 联机：主菜单 → 多人游戏 → 创建房间，把窗口里的地址和 4 位房号发给朋友

手机 / 平板（与电脑同一个游戏，不装任何东西）：

1. 双击项目根目录的 `启动局域网服务器.bat`（英文副本 `start_lan.bat`）
2. 手机与电脑连同一个 Wi-Fi，浏览器打开窗口显示的地址或直接扫码
3. 先横屏，再进「多人游戏 → 创建 / 加入房间」

> 第一次运行如弹防火墙提示，把「专用」和「公用」都勾上，否则手机热点连不进来。

## 技术栈

| 类别 | 选型 |
|:--|:--|
| 前端 | 原生 JavaScript + HTML5 Canvas + WebAudio，无框架无依赖 |
| 联机 | WebSocket，服务器为 Python 标准库手写实现（零第三方依赖） |
| 桌面壳 | pywebview（Edge WebView2） |
| 打包 | PyInstaller onefile |
| 测试 | Node 内置 vm 模块做无头集成测试；联机用双沙箱接内存网线跑真实协议（`tests/_netpair.js`） |
| 构建 | `scripts/build.py` 把 `src/js` 合并成单文件 html，`--web` 另外拆出一份外链版 |

## 开发

```bash
python scripts/build.py --version 4.36   # 构建单文件产物到 dist/
python scripts/build.py --keep --web     # 另出一份 dist/web（game.js 外链 + 素材分文件）
python scripts/sync_server.py            # 构建 + 同步 dist/web 到服务端目录 + 引用自检
node tests/run_tests.js --fast           # 全量回归（2400+ 条）
python 服务端/server.py --server --port 8123
```

发布前所有测试全绿再打包。

> **同步服务端请走 `scripts/sync_server.py`，别手工 `cp game.js`。**
> 服务端把两张背景原图转成了 webp（省 300KB+），而 `build.py` 生成的素材清单按 dist
> 里实际存在的文件名写死，手工只覆盖 `game.js` 会让清单指向不存在的 `.jpg`，
> 结果是主菜单立绘和角色背景静默 404。脚本会自动改写这类引用，并打印缺失数。

## 平衡与文档

- `dist/balance.js`：技能伤害、CD、血量、能量、暴击等数值集中在这一份，改完刷新即生效，删掉就回默认
- `docs/使用说明.txt`：面向玩家的操作与系统说明
- `docs/CHANGELOG.md`：版本变更记录
- `AGENTS.md`：技术栈与架构约定，随代码维护
