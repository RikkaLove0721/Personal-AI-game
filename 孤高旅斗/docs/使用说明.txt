# 使用说明

## 怎么启动

  进入 dist/ 目录, 双击「孤高旅斗.exe」即可。
  - 会先弹出一个黑色窗口(服务器状态), 然后自动打开游戏窗口。
  - 黑窗口不要关, 关掉 = 关服务器(联机就断了)。
  - 第一次运行如果弹出防火墙提示, 请把「专用网络」和「公用网络」都勾上再点允许。
    (只勾专用的话, 用手机热点联机会连不上)

  也可以直接双击 dist/孤高旅斗.html 用浏览器玩单人内容; 但联机必须走 exe(要服务器)。


## 操作

  W A S D / 方向键     四向移动
  快速双击同一方向键    短距离闪避(无无敌帧, 冷却 2.5 秒)
  J                   普攻
  K                   技能 1
  L                   技能 2
  O                   大招(需要能量满)
  V                   切换索敌目标(Shift+V 反向)
  M                   静音
  Esc                 返回主菜单

  索敌: 被锁定的对手头顶有黄色三角, 追踪类与瞄准类技能会优先朝它出手;
  锁定目标倒下后自动回退到最近的敌人。


## 战斗规则

  - 勇者 200 血。大招需要能量满 150: 命中敌人 +12, 被击中 +10, 每秒自然回复 2.2。
  - 任何角色(包括巨龙)开大招时, 全场暂停并给局部特写, 技能名逐字出现——这是预警, 注意躲。
  - 默认普攻: 「斩击」。格挡已归入普攻分类(装在 J 槽), 二选一。
  - 格挡: 空放或挡下普攻 -> 冷却 2 秒; 挡下技能或大招 -> 冷却 8 秒。
  - 格挡还能把飞来的远程攻击原路反弹, 反弹后伤害更高。
  - 位移类技能冲刺过程中无敌, 可以穿过弹幕; 双击闪避没有无敌帧, 纯靠走位。


## 模式(2.0 新增, 单人与联机都可选)

  乱斗模式   所有人互相为敌, 最后站着的赢下回合
  阵营模式   红黄蓝绿四队, 同队互不造成伤害(名字前有队伍色点),
             只剩一个阵营时获胜; 全同阵营不能开局
  霸主争霸   巨龙同场混战; 击败巨龙会爆出能量石并飞向随机位置,
             第一个抢到的人成为霸主: 血量上限与当前血量 x1.5, 头顶皇冠,
             人机仇恨转向霸主; 霸主阵亡后石头掉回场上重新争夺


## 技能与数值(2.0)

  - 普攻: 斩击 1.6s / 远程普攻 2.1s / 格挡 0.4s / 手枪 5s / 石头 4s / 狼牙棒 5s
      手枪: 高速直线弹, 伤害与火球相当, 纯靠准头
      石头: 伤害不高, 命中眩晕 0.4 秒, 打断和起手都好用
      狼牙棒: 蓄力 0.3 秒后砸下, 范围与伤害都比斩击大, 前摇是破绽
  - 技能: 位移斩 3.2s / 激光波 8s / 风刃 5.5s / 冥思 4.5s / 岩土盾 8s /
    神龙掌 8s / 肉弹冲击 8s / 飞雷神 6s / 粪击 7s / 瞬身 7.5s / 替身 5s / 嗜血斩 8s
  - 激光波: 蓄力 1.1 秒(蓄力中双击方向键可直接取消), 方向锁定为出手朝向,
    之后朝正前方轰出贯穿激光(宽 128, 射程 540)
  - 神龙掌: 吸收沿途远程攻击, 最多吸收 20 点伤害, 超出则掌印被射爆提前消失
  - 肉弹冲击: 移速大幅提升 3 秒, 撞到对手造成伤害并撞飞(不再眩晕)
  - 飞雷神: 掷出无伤害飞镖, 再按一次瞬移到飞镖处并爆炸(26 点伤害)
  - 粪击: 命中致盲 3 秒, 遮蔽视野但不锁操作
  - 弹幕强化: 虚空爆裂斩与神龙掌体型翻倍; 全部飞行物大幅提速——
    别站桩, 多用双击闪避和格挡


## 单人: 巨龙格斗(关卡制)

  每一关有普通 / 困难两档:
    普通   奖励 4 金币    怪物血量 x1.00  伤害 x1.00  出手频率 x1.00
    困难   奖励 10 金币   怪物血量 x1.55  伤害 x1.40  出手频率 x1.38
  第一关: 熔核巨龙
    - 普攻 火球: 会轻微追踪你的走位
    - 一技能 突刺爪击: 出现红圈预警后直线冲刺, 看到红圈就闪
    - 大招 爆裂火焰: 蓄力后全场落下多道火柱
  巨龙血量降到 62% / 32% 会进入更狂暴的阶段, 弹幕更密, 出手更快。


## 单人: 勇者格斗(角色卡房间)

  进去就是一张「角色卡」房间: 第一张卡是你自己, 可以当场换装扮和技能。
  后面的人机卡可以「添加 / 删除」(最多 3 个), 每张可选难度(木桩 / 普通 / 困难)
  与四槽配装, 也能一键随机。顶部选好模式(乱斗 / 阵营 / 霸主)后点「开始对决」。
  胜利奖励: 普通 +6 金币, 困难 +12 金币。
  人机对手的皮肤每局随机搭配(头/上身/下身各自随机)。


## 多人: 局域网对战(2-4 人)

  1. 所有电脑连同一个 Wi-Fi 或手机热点。
  2. 房主双击 dist/孤高旅斗.exe, 等游戏窗口打开。
  3. 房主: 主菜单 -> 多人游戏 -> 创建房间, 得到 4 位房号。
  4. 朋友(最多 3 位): 不要启动自己的 exe! 直接用浏览器打开房主给的地址
     (形如 http://192.168.1.5:8123), 然后 多人游戏 -> 加入房间 -> 输入房号。
  5. 房间准备阶段所有人都是角色卡: 可以换装扮 / 技能; 房主可以增删人机(最多 3 个)
     并选择模式, 2-4 人随时开局。
  6. 房主点「开始对决」。乱斗 / 阵营 / 霸主争霸规则见上面的模式说明。

  连不上排查:
    1) 两台设备是不是同一个 Wi-Fi / 热点
    2) 房主防火墙是否放行「孤高旅斗.exe」访问网络
    3) 黑窗口是否还开着
    4) 手机热点可能开了「AP 隔离」, 需到热点设置里关闭
    5) 房号是 4 位数字, 别输错


## 金币与商店

  - 击败巨龙: 普通 +4 金币, 困难 +10 金币(每次通关都给)
  - 皮肤商店: 头部 / 上身 / 下身三段式 Q 版模型, 自由混搭, 每件 6 金币
      头部可选: 机器人, 年轻男子, 粉发少女, 江湖斗篷侠, 高帽企业家(各有配色)
  - 技能商店: 普攻 6 金币, 技能 6 金币, 大招 10 金币
      最多携带 1 个普攻 + 2 个技能 + 1 个大招, 买完点「装配」即可换上
  - 游戏帮助页面最下方有一个作弊按钮, 每按一次 +10 金币(自己玩得开心就好)


## 文件说明

  dist/孤高旅斗.exe   双击启动(原生窗口 + 内置局域网服务器, 无需安装任何东西)
  dist/孤高旅斗.html  游戏本体, 也可以单独用浏览器打开玩单人内容
  docs/              使用说明(本文件)与更新日志
  src/               完整源码(前端模块 + Python 服务器)
  scripts/           构建脚本
  tests/             自动化测试

  启动时黑窗口会打印一行「游戏文件: 孤高旅斗.html(外部更新版 / EXE 内置版)」:
    - 外部更新版 = 用的是 exe 旁边那个 .html(更新只用换这个文件)
    - EXE 内置版 = exe 旁边没有 .html, 用的是打包在 exe 里的副本


## 后续更新玩法(不用重新打包!)

  exe 会优先读取「和 exe 放在同一个文件夹」的 孤高旅斗.html。
  所以以后更新时只要:
    1. 改 src/js/ 里的模块
    2. 运行  python scripts/build.py        (生成新的 dist/孤高旅斗.html)
    3. 重新打开 exe —— 新玩法立刻生效, exe 本身不用动


## 给开发者

  模块化构建: src/js/*.js(数据/AI/战斗/渲染/联机/界面 分层)
  改完模块后运行  python scripts/build.py --version x.y  重新生成 dist/孤高旅斗.html。
  发布前自测(全绿再发):
    node tests/test_smoke.js     集成自测 70 项
    node tests/test_net.js       联机自测 33 项
    node tests/dodge_check.js    闪避与激光波回归 10 项
    node tests/srv_check.js      Python 服务器自测 24 项(需先 --server 开服)
