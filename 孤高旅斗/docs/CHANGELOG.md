## 2.5.1 (2026-09-21)

### 修复: 神秘黑侠客完全不使用技能
- 根因: AI 决策里 n_clone(暗影分身)分支写成「直接 return true」却没按下按键, 分身永远召不出来; 更糟的是它返回 true 表示"这一手已出手", 于是技能 2(突袭)也永远轮不到, 整场只会扔飞镖
- 修复: 该分支改为真正按下技能键; 现在黑侠客会正常召分身 + 突袭

### 修复: 西部快枪手打不出普攻
- 根因: g_shot 直接复用了手枪的 IMPL, 而手枪读的是 sk.proj.speed 这种嵌套写法, BOSS 普攻配置用的是扁平的 speed/r/life, 于是 sk.proj 为 undefined 抛异常, 快枪手一枪都发不出来(异常还会吞掉那一帧剩余的战斗更新)
- 修复: 给快枪手写独立实现, 兼容两种字段写法, 并把难度倍率 rateM 计入 CD

### 技能调整
- 螺旋手里剑(黑侠客大招): 每段伤害 8 -> 12
- 螺旋手里剑上架大招商店: 勇者也能买(大招 10 金币), 与 BOSS 同款数值: 中速巨球 4.5 秒 / 中度吸引 / 每 0.35 秒 12 伤
- 王从天降: 二段飞起期间释放者被定身, 不能移动也不能使用任何技能(含位移类), 落地立刻恢复; 此前可以一边飞天一边位移放招

### 其他修复与优化
- 困难模式的伤害倍率对人形 BOSS 生效: 原先只判 kind === "dragon", 黑侠客/快枪手的 dmgM 形同虚设; 现在 3 关怪物的困难伤害统一 x1.40
- 远程 BOSS 站位: AI 的远程判定同时认 proj 与扁平 speed, 黑侠客/快枪手不再贴脸; 突袭改为定身式突进, 避免一边后撤一边挥刀打空
- 天外来物拾取失灵: 同类掉落物的旧待置换失效时, 清理逻辑跑在拾取之后, 会挡住脚下新掉落物的挂起(要走出再走回来才恢复); 改为先清理再拾取
- 天外来物置换: 技能与大招各挂一个待置换, K/L 与 O 互不干扰(此前同种只能挂一个, 站在两个掉落物中间会互相顶掉)

### 文案
- 单人「巨龙格斗」更名为「闯关模式」(主菜单 / 关卡页 / 帮助 / 文档同步)
- 天外来物模式介绍精简(去掉重复细节, 保留 10 秒 / 20 秒 / 置换 / 留在地上等关键规则)

### 测试
