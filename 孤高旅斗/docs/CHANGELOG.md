## 2.0 (2026-09-18)

### 项目调整
- 总文件夹改名为「孤高旅斗」, 本版本号定为 2.0(用户指定, 不走自动递增)
- 上一轮的普攻/闪避共享冷却与岩土盾削弱(原记在 1.4.4)随本次一并发布

### 数值与机制调整
- 神龙掌 CD 6s -> 8s, 且吸收伤害封顶 20 点; 超出后掌印直接被射爆提前消失(弹出「掌印被破!」)
- 风刃弹速 430 -> 560, 更好命中
- 替身爆炸半径 82 -> 118, 爆炸附带 0.6 秒眩晕
- 肉弹冲击 CD 6s -> 8s, 移除眩晕(改为纯加速 + 撞飞)
- 激光波蓄力 1.5s -> 1.1s
- 激光波蓄力期间双击方向键: 直接取消该技能(进入 2 秒短 CD), 不再允许用闪避位移把激光带到别的朝向
- 格挡从「技能」改归「普攻」分类(装在 J 槽); 机制不变: 空放/挡普攻 2 秒 CD, 挡技能/大招 8 秒 CD; 格挡的反制 CD 不再连带锁死闪避
- 旧存档自动迁移: 原本放在 K/L 槽的格挡自动挪到 J 槽, 不会变成空槽

### 重大 BUG 修复: 非房主看不到暴击与拖尾
- 根因一: 房主广播的 `ce` 特效事件(伤害数字/暴击/弹反/致盲)在客机的消息分发里根本没有分支, 全部被静默丢弃
- 根因二: 客机的弹道由快照重建, 只补了位置, 没有逐帧生成拖尾粒子
- 修复: 补上 `ce` 事件处理与「b」类浮动文字; 客机在插值循环里为带拖尾的弹道本地生成尾迹

### 新增: 索敌机制
- 当前锁定的对手头顶显示黄色三角标记
- 按 V 在存活敌人之间循环切换(Shift+V 反向), 锁定信息随快照同步给客机
- 追踪类与需要瞄准的技能(远程普攻、瞬身等)优先朝锁定目标出手; 锁定目标倒下自动回退最近敌人
- 人机同样使用索敌(霸主模式下非霸主人机仇恨自动转向霸主)

### 新增: 三种对战模式(单人与联机都可选)
- 乱斗模式: 所有人互相为敌, 最后站着的赢下回合
- 阵营模式: 红黄蓝绿四队, 同队互不造成伤害(名字前带队伍色点), 只剩一个阵营时获胜; 全同阵营禁止开局
- 霸主争霸: 巨龙同场混战; 击败巨龙爆出能量石并飞向随机位置, 第一个拾取者成为霸主(血量上限与当前血量 x1.5, 头顶皇冠), 霸主阵亡后石头掉回场上重新争夺

### 新增: 角色卡房间
- 单人「勇者格斗」与多人准备阶段都改用同一套角色卡界面
- 第一张卡永远是玩家自己, 可在房间内直接换装扮/技能/总览(换完返回不丢房间状态)
- 人机卡可增删(最多 3 个), 每张可选难度(木桩/普通/困难)与四槽配装, 也可一键随机
- 多人模式: 房主可增删人机、切换模式; 房间状态通过 room 消息同步给所有客机
- 加入房间独立成单独界面(主菜单 -> 多人游戏 -> 创建房间 / 加入房间)

### 新增技能与普攻
- 普攻格挡(由技能迁移), 手枪(CD 5s, 高速直线弹, 伤害与火球相当), 石头(CD 4s, 命中眩晕 0.4s), 狼牙棒(CD 5s, 0.3s 前摇的近战重击)
- 技能: 飞雷神(CD 6s, 掷出无伤害飞镖, 再按一次瞬移到飞镖处并爆炸 26 点伤害), 粪击(CD 7s, 命中致盲 3 秒, 遮蔽视野但不锁操作)

### 联机扩到 4 人
- 服务器房间扩为 4 席(房主 + guest/guest2/guest3), 第五人加入时提示房间已满(4/4)
- 快照与弹道包新增 blind/overlord/team/lock/trail/basic/kindTag/stun/blind 字段, 4 人战斗完整同步
- HUD 支持最多 3 个对手的血条, 并标注队伍/霸主/已倒下

### 平衡配置
- dist/balance.js 与 src/config/balance.js 同步更新到 v2.0 数值, 并补充全部新技能条目(此前 balance.js 会覆盖源码默认值, 导致新数值不生效)

### 其他
- 角色卡房间样式(卡片/模式选择/阵营选择/技能下拉)与滚动布局适配, 内容超高时不再顶住返回按钮
- 测试新增 tests/test_v20.js(83 项)覆盖数值/新技能/索敌/三模式/能量石/房间; test_net 扩到 4 人(35 项); srv_check 扩到 4 席位(26 项)

## 1.4.3 (2026-09-17)

### 数值与手感

- 激光波 CD 5s -> 8s
- 激光波蓄力期间朝向彻底锁定: 出手瞬间记录角度, 蓄力中施放其他技能不再改变激光方向
- 千剑杀弹道重做: 不再逐发追踪对手, 改为施放瞬间锁定朝向后直线倾泻, 靠走位输出

### 重大 BUG 修复: 巨龙攻击不可见

- 根因: 注册巨龙技能时只拷贝了 cd 和 dmg 两个字段, 火球的 speed/r 是 undefined (弹道为 NaN, 等于从未发射), 爪击的 windup 是 undefined (永远卡在前摇)。玩家一直看不到巨龙的普通攻击
- 此前测试通过是因为大招火柱单独使用了完整配置对象
- 修复: 注册时并入完整配置; 火球新增 0.45s 蓄力前摇 (龙眼变红 + 嘴部聚能) 与更大的弹体 (r 11 -> 15), 攻击可读性大幅提升

### 存档修复

- exe 模式下存档新增服务器侧落盘 (profile.json, 位于 exe 旁边), 与 localStorage 双写, 按 rev 修订号新者胜; 端口漂移或 WebView 数据丢失不再导致进度清零
- 服务器新增 GET/POST /api/profile 接口

### 平衡配置文件

- 新增 balance.js: 技能伤害/CD/血量/能量/暴击/闪避/格挡/巨龙数值全部可调, 改完刷新即生效, 无需重新构建
- 构建时自动复制默认配置到 dist/ (不覆盖已有文件); exe 优先读取 exe 旁边的 balance.js

### 美工

- 主界面与各分界面背景更换为用户提供的插画 (标题与卡片区域压深色渐变保证可读)
- exe 图标更换为用户提供的插画 (多尺寸 ico)
